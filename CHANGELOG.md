# Changelog

`tak-gateway` versions for OpenWrt routers and Hak5 WiFi Pineapples. Newest first.

## 0.1.0
- First public release: `tak-gateway` bridges local TAK multicast (SA and GeoChat) to a TAK Server.
- **LuCI page** (`luci-app-tak-gateway`) with status and settings.
- Packages for OpenWrt (`.apk`) and for Hak5 Pineapples (mips and mipsel `.tar.gz`).
